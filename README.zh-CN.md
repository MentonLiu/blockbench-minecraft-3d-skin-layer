# Minecraft 3D 皮肤层

[![License: MIT](https://img.shields.io/badge/MIT%20License-yellow.svg)](LICENSE)
[![Release](https://img.shields.io/badge/release-v0.4.0-blue.svg)](../../releases)
[![Blockbench](https://img.shields.io/badge/Blockbench-5.0%2B-orange)](https://blockbench.net)

[English](README.md) | 简体中文

把任意 Minecraft 皮肤变成 **3D 体素模型**：每个像素生成一个方块，六个面全部映射到该像素。既可以从内置模板新建皮肤并直接在体素上绘制，也可以转换现有的皮肤模型——每一步都是可撤销的原子操作。

![Blockbench 中生成的体素层](docs/images/preview.png)

## 安装

1. 从[最新发布页](../../releases)下载 `minecraft_3d_skin_layers.js`（或自行构建：`npm run build`）。
2. 在 Blockbench 中：**文件 > 插件 > ... > 从文件加载插件**，或将文件复制到 Blockbench 的 `plugins` 文件夹。
3. 需要 Blockbench **5.0.0+**（桌面版）。

## 功能入口一览

| 入口 | 作用 |
|---|---|
| 开始界面 / **文件 > 新建 > 3D 皮肤模型** | 新建向导：选模板 + 纹理尺寸（可填模型名称 / 标识符，均可留空），直接生成全量体素模型 |
| **3D 皮肤模型 > Generate 3D Skin Layers（生成 3D 皮肤层）** | 体素化当前模型的 `... Layer` 立方体 |
| **3D 皮肤模型 > 重新生成方块** | 按当前纹理原位重建体素 |
| **3D 皮肤模型 > Restore 3D Skin Layers（还原 3D 皮肤层）** | 把已生成的分组还原回原始单个立方体 |
| **3D 皮肤模型 > 清除透明方块** | 删除采样像素已透明的体素 |

## 快速上手 A —— 绘制一张新皮肤（推荐）

1. **开始界面 / 文件 > 新建 > 3D 皮肤模型**。
2. 在向导中选择**模板**（经典 / 根分组 / 关节分段）和**纹理尺寸**（64 或 128），也可按需填写**模型名称**与**模型标识符**（均可留空：名称留空用模板默认名，标识符留空则不设置）。对应纹理会加载进模板，**所有像素——包括透明像素——都会生成方块**，随时可以下笔绘制。
3. 直接绘制皮肤（绘制模式下即可操作，纹理就是一张普通皮肤）。
4. 随画随清理：
   - **3D 皮肤模型 > 清除透明方块**：删除仍是透明像素处的方块。
   - 大幅重画后，**3D 皮肤模型 > 重新生成方块**：按当前纹理重建全部体素，分组上的姿态会保留。

每一步都是一次撤销事务（`Ctrl/Cmd + Z` 即可回退）。

## 快速上手 B —— 体素化现有的皮肤模型

1. 在**编辑模式**打开模型，模型中需有名为 `... Layer` 的立方体（`Hat Layer`、`Body Layer1`……关节模型的数字后缀也可以）。层立方体的几何与 UV 就是唯一依据，64×64、128×128 以及自定义布局都能直接工作，无需硬编码图集。
2. 运行 **3D 皮肤模型 > Generate 3D Skin Layers（生成 3D 皮肤层）**。预检弹窗会显示找到的层数与像素数，调整选项后确认。
3. 想拿回原始模型：运行 **3D 皮肤模型 > Restore 3D Skin Layers（还原 3D 皮肤层）**——生成的分组保存了完整的原始立方体数据（保存后重开项目依然有效）。

生成与还原弹窗底部都有 **使用新模型项目** 勾选框：勾选后先复制项目再在副本上执行——原标签页保持不变，且副本不继承原项目的保存路径（保存副本时一定会询问位置，绝不会覆盖原文件）。

## 各命令详解

### Generate 3D Skin Layers（生成 3D 皮肤层）
- 每个非透明像素生成一个完整体素，六面全部映射到该像素；厚度与层膨胀值一致，外壳精确复现原第二层轮廓。
- 用同名分组替换原 `... Layer` 立方体，整个过程是一次原子撤销；超过方块上限时在修改前即中止。
- 幂等：已生成的分组不会被重复处理。

### 新建 3D 皮肤模型向导
- 模板内置于插件，无需额外文件。128 尺寸在相同的 64 单位 UV 空间加载 128×128 纹理（2 倍像素密度，如头部正面 16×16）。
- 可选的**模型名称**会成为项目（标签页）名；可选的**模型标识符**保存为 bbmodel 的 `model_identifier`（之后也可在 文件 > 项目 中修改）。两者都可以留空。
- 创建后立即体素化，**包含透明像素**，直接进入"绘制—清理"循环。

### 清除透明方块
- 删除采样像素已变为透明的体素。天然安全：只考虑插件生成分组内的方块，且其 UV 必须恰好覆盖一个像素。

### 重新生成方块
- 重新扫描当前纹理，原位重建所有已生成的分组。分组（以及你在分组上摆的姿态）保留，只替换体素方块。重画之后用它，不需要先撤销。

### Restore 3D Skin Layers（还原 3D 皮肤层）
- 插件生成的分组保存了完整源数据，还原可精确重建原始立方体并移除体素。0.3.1 之前的旧分组采用尽力兼容重建。

## 选项参考

所有选项都会跨会话记忆。

| 选项 | 出现位置 | 默认值 | 说明 |
|---|---|---|---|
| 使用新模型项目 | 生成 / 还原弹窗 | 关 | 复制为新项目并在副本上修改 |
| Alpha 阈值 | 生成弹窗 | 0 | Alpha 高于该值的像素生成方块 |
| 最大方块数量 | 生成弹窗 | 10,000 | 超过即中止，模型不做任何修改 |
| 每批方块数 | 生成弹窗 | 200 | 大模型的 UI 让出频率 |
| 保留原始层立方体 | 生成弹窗 | 关 | 隐藏而非删除源立方体 |
| 替换全透明层 | 生成弹窗 | 关 | 为空层生成空分组 |
| 仅处理选中层 | 生成弹窗 | 关 | 只处理被选中的层立方体 |
| 项目打开时自动生成 | 生成弹窗 | 关 | 打开项目时自动运行 |
| 包含透明像素 | 重新生成弹窗 | 关 | 每个网格单元都生成方块，透明像素也不例外 |

## 行为要点

- **同部位无 Z 轴闪烁**：面外壳带不可见偏移（最大 0.0075）。默认姿势下互相穿透的部位（双腿、腰部）有意共享平面——摆姿势后即分离。
- **分辨率自适应**：像素网格由纹理尺寸与 UV 空间推导，绝不硬编码。
- **多纹理、反向 UV、面旋转**（0/90/180/270）均按面正确处理。
- **中英文界面**，基于 Blockbench 原生翻译系统。

## 已知限制

- 层边缘在极端掠射角下可能看到一条细缝。
- 仅支持桌面版；网页版未测试。
- 重新生成要求插件生成的分组（带元数据）；0.3.1 之前的旧分组仅支持还原。
- 设计上不做相邻像素合并：一个像素一个方块是核心契约。
