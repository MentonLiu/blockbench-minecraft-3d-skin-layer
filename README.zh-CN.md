# Minecraft 3D 皮肤层（Minecraft 3D Skin Layers）

[English](README.md) | 简体中文

一个 Blockbench 插件，把 Minecraft 皮肤变成真正的 3D 体素模型：每个像素生成一个完整方块，六个面全部映射到该像素。既可以基于内置模板新建全量体素皮肤并直接绘制，也可以把现有皮肤模型的 `... Layer` 外层转换为体素——所有操作都是可撤销的原子事务。

## 功能特性

- **一像素一方块**——每个体素的六个面都映射到同一个源像素，厚度与层的膨胀值（inflate）一致，外壳精确复现原皮肤层轮廓。
- **先画后建的工作流**——开始界面 / 文件 > 新建中的 *3D 皮肤模型* 格式会打开新建向导（选模板、纹理尺寸，可填名称与标识符），直接交付一个已体素化的模型，透明像素也生成方块，随时可以下笔。
- **完全可逆**——生成的分组保存了完整的源立方体数据，还原可精确重建原始模型，保存后重开项目依然有效。
- **分辨率自适应**——像素网格由纹理尺寸与 UV 空间推导，64×64、128×128 以及自定义布局都能直接工作，无需硬编码图集。
- **中英双语界面**，基于 Blockbench 原生翻译系统。

## 安装

1. 从[最新发布页](../../releases)下载 `minecraft_3d_skin_layers.js`（或自行构建：`npm run build`）。
2. 在 Blockbench 中：**文件 > 插件 > ... > 从文件加载插件**，或将文件复制到 Blockbench 的 `plugins` 文件夹。
3. 需要 Blockbench **5.0.0+**（桌面版）。

## 功能入口一览

| 入口 | 作用 |
|---|---|
| 开始界面 / **文件 > 新建 > 3D 皮肤模型** | 新建向导：选模板 + 纹理尺寸（可填模型名称 / 标识符，均可留空），直接生成全量体素模型 |
| **3D 皮肤模型 > 生成 3D 皮肤层** | 体素化当前模型的 `... Layer` 立方体 |
| **3D 皮肤模型 > 重新生成方块** | 按当前纹理原位重建已生成的体素 |
| **3D 皮肤模型 > 还原 3D 皮肤层** | 把已生成的分组还原回原始单个立方体 |
| **3D 皮肤模型 > 清除透明方块** | 删除采样像素已变透明的体素 |

只要打开了项目，菜单栏（**文件**旁）就会出现 **3D 皮肤模型** 菜单。

Blockbench 桌面版可选接入 [Blockbench MCP](docs/MCP.md)，让 MCP 客户端调用这些功能；未安装 MCP 时插件界面仍可正常使用。

## 快速上手 A——绘制一张新皮肤（推荐）

1. 打开开始界面或 **文件 > 新建 > 3D 皮肤模型**。
2. 在向导中选择**皮肤类型**（Steve 或 Alex，默认 Steve）、**模板**（默认模型、Blockbench 经典或关节模型，默认选中默认模型）和**纹理尺寸**（64 或 128），也可按需填写**模型名称**与**模型标识符**（均可留空：名称留空使用 `temp-<尺寸>` 项目名，标识符留空则不设置；之后都可在 文件 > 项目 中修改）。对应的 Steve/Alex 纹理会加载进模板，**所有像素——包括透明像素——都会生成方块**，随时可以下笔绘制。
3. 直接绘制皮肤（绘制模式下即可操作，纹理就是一张普通皮肤）。
4. 随画随清理：
   - **清除透明方块**：删除仍是透明像素处的方块。
   - 大幅重画后，**重新生成方块**：按当前纹理重建全部体素，分组上的姿态会保留。

每一步都是一次撤销事务（`Ctrl/Cmd + Z` 即可回退）。

## 快速上手 B——体素化现有的皮肤模型

1. 在**编辑模式**打开模型，模型中需有名为 `... Layer` 的立方体（`Hat Layer`、`Body Layer1`……关节模型的数字后缀也可以）。层立方体的几何与 UV 就是唯一依据，64×64、128×128 以及自定义布局都能直接工作，无需硬编码图集。
2. 运行 **3D 皮肤模型 > 生成 3D 皮肤层**。预检弹窗会显示找到的层数与像素数，选择其余选项后确认。Alpha 处理、10,000 方块上限和批次大小使用固定默认值。
3. 想拿回原始模型，运行 **3D 皮肤模型 > 还原 3D 皮肤层**——生成的分组保存了完整的原始立方体数据（保存后重开项目依然有效）。

生成与还原弹窗底部都有 **使用新模型项目** 勾选框：勾选后先复制项目再在副本上执行——原标签页保持不变，且副本不继承原项目的保存路径，保存副本时一定会询问位置，绝不会覆盖原文件。

## 各命令详解

### 新建 3D 皮肤模型（向导）

- 模板内置于插件，无需额外文件。128 尺寸在相同的 64 单位 UV 空间加载 128×128 纹理（2 倍像素密度，如头部正面 16×16）。
- 可选的**模型名称**会成为项目（标签页）名；可选的**模型标识符**保存为 bbmodel 的 `model_identifier`（之后也可在 文件 > 项目 中修改）。
- 创建后立即体素化，**包含透明像素**，直接进入"绘制—清理"循环。若本次需要超过 10,000 个方块，新建项目会保留为未体素化的模板，并提示实际需求数量和固定上限。

### 生成 3D 皮肤层

- 每个非透明像素生成一个完整体素，六面全部映射到该像素。
- 用同名分组在原来的父级 / 兄弟位置替换源 `... Layer` 立方体，整个过程是一次原子撤销；超过方块上限时在修改前即中止。
- 幂等：已生成的分组不会被重复处理。打开项目时插件会自动扫描层立方体，只有勾选 **打开项目时自动生成** 才会真正自动运行。

### 重新生成方块

- 重新扫描当前纹理，原位重建所有已生成的分组。分组（以及你在分组上摆的姿态）保留，只替换体素方块。重画之后用它，不需要先撤销。
- 弹窗提供 **包含透明像素** 勾选框，可让每个网格单元都生成方块。

### 还原 3D 皮肤层

- 插件生成的分组保存了完整源数据（几何、变换、可见性、渲染设置、纹理、UV、面旋转），还原可精确重建原始立方体并移除体素。0.3.1 之前的旧分组采用尽力兼容重建。

### 清除透明方块

- 删除采样像素已变为透明的体素。天然安全：只考虑插件生成分组内的方块，且其 UV 必须恰好覆盖一个像素。

## 选项参考

可调整的选项会跨会话记忆。Alpha 阈值固定为 0，单次上限固定为 10,000 个方块，每批创建数量固定为 200。

| 选项 | 出现位置 | 默认值 | 说明 |
|---|---|---|---|
| 保留原始皮肤层立方体 | 生成弹窗 | 关 | 隐藏而非删除源立方体 |
| 用空组替换完全透明的皮肤层 | 生成弹窗 | 关 | 为空层生成空分组 |
| 仅处理选中的皮肤层立方体 | 生成弹窗 | 关 | 只处理被选中的层立方体 |
| 打开项目时自动生成 | 生成弹窗 | 关 | 打开项目时自动运行 |
| 使用新模型项目 | 生成 / 还原弹窗 | 关 | 复制为新项目并在副本上修改 |
| 包含透明像素 | 重新生成弹窗 | 关 | 每个网格单元都生成方块，透明像素也不例外 |

## 行为要点

- **同部位无 Z 轴闪烁**：面外壳带不可见的逐方向偏移（最大 0.0075）。默认姿势下互相穿透的部位（双腿、腰部）有意共享平面——摆姿势后即分离。
- **多纹理、反向 UV、面旋转**（0/90/180/270）均按面正确处理。
- 生成、重新生成、还原、清除各自都是一次原子撤销事务，失败时自动回滚。

## 已知限制与路线图

- 支持桌面版、网页版与移动端（PWA）；在手机上为整张皮肤生成体素（数百到约 1600 个方块）会比桌面端明显更慢。
- 层边缘在极端掠射角下可能看到一条细缝。
- 重新生成要求插件生成的分组（带元数据）；0.3.1 之前的旧分组仅支持还原。
- 设计上不做相邻像素合并：一个像素一个方块是核心契约。
