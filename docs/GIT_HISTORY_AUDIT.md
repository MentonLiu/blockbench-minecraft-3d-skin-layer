本项目处于 `0.x` 阶段。历史 `0.1.2`、`0.3.1` 等版本含新增功能，但没有
仅据提交类型重新命名其版本。公共 API 稳定之前须遵循项目明确的早期
版本规则；从本次治理起为新版本按变化集合确定版本，不按提交数量或
修复数量递增，不改变已经固定的历史名称。

`0.4.0-pre`、`0.4.0-pre2`、`0.5.0-pre` 是预发布版本；既有名称继续保留，
后续快照或预发布编号遵循新的仓库规范。选择已有 Tag 创建 Release 时

版本。已知 `v0.2.1` 冲突必须先核实，不能被通用发布命令自动绕过。

## 复核方式

以下命令只读取状态；Tag 比较应解析到提交，避免把 annotated Tag 对象
SHA 与源码 SHA 混淆：

```bash
git log --all --graph --decorate --oneline
git rev-list --count --all
git rev-list --all --merges
git reflog show main --date=iso
git rev-parse 'v0.2.1^{commit}'
git ls-remote --tags origin 'v0.2.1' 'v0.2.1^{}'
git show 208f771da8a32a2ee02f0ae47851ae544a35ba6d:package.json
git show 6d15b585c9832bd7e7d19e5b9d358b4c3de5fa5e:package.json
git log -- minecraft_3d_skin_layers_v0.4.0-pre.js
```

上面的提交总数会随后续治理提交增加，不能将新增数量误认为原历史被
重写。遇到本地与远端 Tag 冲突时先保存双方来源并核实，不使用
`fetch --tags --force` 或强推 Tag 消除审计证据。
